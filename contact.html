About Iron & Macros

Iron & Macros is a class project for CIS 332, built as a weekly workout and nutrition tracker for lifters running a 6-day push/pull/legs split.

The site keeps everything a lifter needs in one place: the split planner with completion checkoffs, a daily macro calculator, a meal log built around high-protein staples, a cardio log, and a reference exercise library.

Creator Info

  • Project: Iron & Macros — CIS 332
  • Purpose: Track lifts, macros, and cardio in one dashboard
  • Stack: HTML5, external CSS, and vanilla JavaScript
  • Hosting: GitHub Pages
